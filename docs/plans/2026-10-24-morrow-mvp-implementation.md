# Morrow MVP 实施计划

- 日期：2026-10-24
- 依据：[Morrow 第一版产品设计](../superpowers/specs/2026-10-24-morrow-community-platform-design.md)
- 目标：交付一个可本地运行、可部署到阿里云、支持邀请制成员真实使用的第一版 Web 应用。

## 1. 技术方案

- Next.js + React + TypeScript 单体应用。
- Node.js 内置 `node:sqlite` 数据库，开发数据文件放本地 `data/`，生产环境使用服务器持久磁盘。
- 原生 CSS 设计系统，不引入大型 UI 框架。
- 浏览器 IndexedDB 保存私密草稿和私人记录。
- 本地文件存储作为媒体第一版实现，通过存储接口隔离，给后续阿里云 OSS 留出替换点。
- Node.js 内置密码哈希、随机令牌和会话机制。
- 使用 Node 测试运行器覆盖规则计算、爵位和权限逻辑。

## 2. 实施顺序

### 阶段 A：项目骨架与设计系统

- 建立 Next.js App Router、TypeScript、ESLint/类型检查脚本。
- 建立日光明亮、单列杂志式视觉系统。
- 建立公共页头、按钮、表单、内容卡片和移动端布局。
- 提供健康检查页和基础错误页。

验收：`npm run build` 通过；桌面和手机宽度无布局溢出。

### 阶段 B：数据与认证

- 建立 SQLite schema、迁移初始化和开发种子脚本。
- 实现邮箱密码注册、邀请码、邮箱验证令牌、会话和退出。
- 实现产品负责人邀请码管理页。
- 实现成员共同约定确认。

验收：邀请码一次性使用；未登录不能写入；会话过期后失效。

### 阶段 C：内容核心闭环

- 实现文字、图片、视频发布。
- 实现单列广场、内容详情和作者删除。
- 实现四表情互斥选择与更改。
- 实现长按反馈菜单。
- 实现至少 10 位反馈参与者、负向达到 20% 后永久隐藏。
- 实现今日精选。

验收：规则测试覆盖 9/10/15 人边界；隐藏内容只对作者可见。

### 阶段 D：评论与本地私密区

- 实现一层文字/表情评论。
- 实现评论 5 人反馈后隐藏。
- 实现 IndexedDB 草稿和私人记录。
- 实现“草稿带入发布页”，发布前不产生服务器请求。

验收：浏览器网络面板中私密区不发起 API 请求；草稿成功公开后删除本地副本。

### 阶段 E：成长、爵位与治理

- 实现贡献事件、每日上限、爵位计算和成长地图。
- 实现公共爵位榜，只展示等级与进度，不展示分数。
- 实现普通规则提案、讨论、一人一票。
- 实现重大方向提案和 19/20 级加权投票。
- 实现每日问题与 30 天课程内容展示。

验收：爵位权限、投票权重、法定人数和共同底线保护可被自动化测试。

### 阶段 F：开源协作与上线准备

- 增加 README、CONTRIBUTING、SECURITY、GOVERNANCE、ROADMAP、CODE_OF_CONDUCT、LICENSE。
- 增加 CI 工作流、秘密扫描配置、生产部署说明和备份说明。
- 完成端到端冒烟测试、可访问性检查和移动端检查。
- 准备 GitHub 公开仓库所需的初始文件，但不自动推送或创建远程仓库。

验收：仓库中无真实用户数据或生产密钥；提交历史干净；部署文档可由另一位开发者独立执行。

## 3. 关键实现约束

- 第一版不依赖外部内容审核服务。
- 公开页面禁止搜索引擎索引。
- 用户内容、邮箱、评论、反馈和生产密钥不得进入 Git。
- 私密区不得调用服务器接口。
- 隐藏结果为终态。
- 任何等级都不能直接隐藏内容。
- 所有数值规则集中在配置模块，便于社区治理后续调整。
- 先保证主流程可用，再补充视觉细节和治理扩展。

## 4. 验证命令

- `npm run typecheck`
- `npm run test`
- `npm run build`
- 本地启动后完成注册、发布、10 人反馈隐藏、精选、评论、私密区、爵位榜和提案投票冒烟流程。

## 5. 交付说明

完成后提供：

- 本地启动步骤。
- 首次创建负责人账号与邀请码的方法。
- 测试账号或种子数据说明。
- 已实现功能与仍依赖生产配置的事项。
- 可部署到阿里云的操作说明。
